# Instalacion

1. Crear el entorno virtual:

```bash
python -m venv venv
```

2. Activarlo en Windows:

```bash
venv\Scripts\activate
```

3. Instalar dependencias:

```bash
pip install -r requirements.txt
```

4. Ejecutar la aplicacion:

```bash
python app.py
```

5. Abrir `http://127.0.0.1:5000/control`.
