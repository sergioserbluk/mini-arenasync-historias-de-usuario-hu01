# Teoría Clase 1: Introducción y puesta en marcha

## Conceptos básicos

- Proyecto web: conjunto de archivos que implementan una aplicación accesible desde un navegador.
- Servidor local: programa que escucha peticiones HTTP en una dirección y responde con páginas web o datos.
- Entorno virtual de Python: espacio aislado donde se instalan dependencias sin afectar al sistema.

## Componentes principales del proyecto

- `app.py`: archivo principal que inicia el servidor Flask.
- `requirements.txt`: lista de librerías necesarias para ejecutar la aplicación.
- `templates/`: archivos HTML que definen la estructura de las páginas web.
- `static/`: recursos estáticos como CSS y JavaScript.
- `services/` y `models/`: lógica de negocio y modelo de datos.

## Objetivos de la sesión

- Conocer la estructura de un proyecto web con Flask.
- Aprender cómo activar un entorno virtual de Python.
- Entender la relación entre rutas y páginas en una aplicación web.

## Por qué es importante

Esta clase proporciona el fundamento para trabajar con el resto de las sesiones. Comprender la estructura y la ejecución evita bloqueos técnicos y permite centrarse en la lógica más adelante.
