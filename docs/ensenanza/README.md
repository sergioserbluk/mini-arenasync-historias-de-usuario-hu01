# Material de enseñanza: Mini ArenaSync

Este folio de enseñanza contiene material didáctico para usar la aplicación Mini ArenaSync como caso práctico en clase.

## Objetivo

- Enseñar el uso de API REST con Python y Flask
- Mostrar comunicación en tiempo real con SocketIO
- Describir el frontend con HTML, CSS y JavaScript
- Explicar lógica de negocio y persistencia con JSON
- Introducir pruebas automatizadas con `pytest`
