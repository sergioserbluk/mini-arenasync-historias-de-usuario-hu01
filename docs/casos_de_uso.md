# Casos de Uso

## CU01 - Iniciar partido

El operador ingresa a `/control`, carga ambos equipos, selecciona la modalidad y presiona "Iniciar partido".

## CU02 - Actualizar puntos

El operador suma o resta puntos desde el panel. El sistema sincroniza automaticamente el tablero.

## CU03 - Registrar set automaticamente

Al llegar a 25 o mas puntos con diferencia minima de 2, el sistema otorga un set y reinicia puntos.

## CU04 - Reiniciar puntos

El operador reinicia solo los puntos. Los sets se mantienen.

## CU05 - Finalizar y guardar partido

El operador confirma la finalizacion y el sistema guarda el resultado.

## CU06 - Consultar historial

El usuario accede a `/resultados` para ver partidos guardados.
