# Historias de Usuario

Este proyecto implementa las historias HU01 a HU10:

- Configurar partido con Equipo A y Equipo B.
- Configurar modalidad de sets.
- Mostrar tablero publico sincronizado.
- Sumar y restar puntos.
- Registrar sets automaticamente.
- Reiniciar puntos.
- Finalizar partido.
- Guardar resultados con puntos totales y diferencia de puntos.
- Consultar resultados guardados.

Las reglas principales estan centralizadas en `services/partido_service.py`.
